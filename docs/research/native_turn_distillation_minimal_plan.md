# Conditional proposal: teach the existing blind-turn controller

Acquisition draft for review, 6 November 2026. **The descriptive teacher preflight has passed technical review and its banks/protocol are frozen; no acquisition training or cloud job is authorized by this document.** The preceding fixed initial/final geometry study is complete and found no ring candidates. The preflight and acquisition proposal remain separate; subsequent acquisition revisions require their own fixed specification.

The new ingredient is dense action supervision. The turn, forward probe, short predictive cue, common suffix and native goal-return task already exist in [the blind-reorientation implementation](rl_blind_reorientation_implementation.md). The previous reward-only and local-return outcomes remain separate. This proposal replaces sparse credit with the full-vision original policy's action probabilities and shortens the ambiguous navigation interval; it does not prescribe a circular representation.

**Initialization and learning.** For each population, use its original 1B seed-1 checkpoint as both teacher and initial student, including the original actor and critic. Do not use a selected checkpoint from the completed 180-update pilot. Freeze the teacher and the student's CNN, actor, critic and spatial-code parameters. Train only the same four existing LSTM tensors with fresh Adam, learning rate 1e-4, gradient clipping at 1, temperature 1 and no added state noise. The native square, maps, six actions, reward, goal cache, image noise and motor noise remain in the training environment. The teacher receives actual full observations and the executed action/reward history, including every imposed action. It follows that actual trajectory rather than rolling out a separate hypothetical history.

**One training event, inside a native episode.** Reuse the audited clock, brakes, code construction and goal/reset conventions, through a new adapter rather than editing their frozen files:

| Phase | Actual physics | Student observation |
|---|---|---|
| Refresh, 15 updates | Policy-controlled navigation | Native RGB/current code |
| Turn A and B, 5–10 updates each | Independently drawn native left/right actions; brake at blind entry | Black RGB; ordinary current code held at blind-entry position |
| Probe, 4 updates | Brake, then four native forward actions | Same held ordinary code |
| Cue and suffix, 4–15 updates | Brake after probe; common native left-turn suffix | One native or ordinary endpoint-code observation on the first suffix update, then held ordinary endpoint code |
| Ambiguous choice, 3 updates | Policy chooses all six actions; brake immediately before its first decision | Black RGB, the same held ordinary endpoint code |
| Resume | Ordinary native policy control | Fresh native RGB/current code restored immediately after choice 3 |

The saved goal code stays native throughout. Actual previous actions and rewards are recorded. Brakes explicitly set `vf`, `vs`, and `vr` to zero at blind entry, before/after the probe, and before the choice window; a turn command is never treated as a natural brake. Record real intermediate drift, wall contacts, probe displacement and pre/post motor values. Actual pickups interrupt the event and update the native goal cache; episode endings clear both recurrent states. Forced rewards and later visible rewards are separately counted. No navigation reward is optimized in this distillation pilot.

The teacher gets full native RGB/current input through the event. On each event, a private fair coin selects the student's one-update native versus ordinary endpoint cue; replacing the 169 predictive entries is an exact Grid sham. The other 343 current entries and all goal/action/reward inputs are identical across cue counterfactuals. After cue withdrawal, all current entries are ordinary and held. Last-travel direction is measured from the actual probe; it is never overwritten with body heading. The suffix turns the body while the earlier travel direction becomes stale, deliberately requiring retention and updating of the cue.

**The precise shortcut being removed.** No fresh position observations enter during the three measured choices, so comparing their successive ordinary codes cannot recover direction. The ordinary probe-endpoint observation can still be compared with the earlier entry position. That legitimate history-based route remains available in the ordinary-cue control; it is not evidence for a specifically predictive mechanism. The primary outcome is the first choice, before a chosen action can become a new external memory. The three-choice outcome and later native navigation are reported separately. After feedback returns, reacquisition is expected and is not credited as retained angular memory.

**First run a teacher-usefulness preflight, before authorizing optimization.** Seal one independent bank from the existing native census: the first 16 geometry-eligible post-discovery contexts per population, in episode/time order, with the same saved goal and full original preceding history. The census collection checkpoint/config hashes are bound to the loaded original; the complete archived recurrent-input prefix is replayed at its original 32-slot batch shape to verify the saved incoming h/c exactly before any pose intervention. Eligibility uses only actual goal/wall clearance, available history and enough remaining original episode time for the entire forced history plus 30 utility steps, never teacher logits, student success or a neural circle. Save the complete eligibility inventory and any missing contexts; do not replace cases after reading the teacher. Use eight antipodal heading pairs per context: 128 pairs / 256 cases. Reuse the deterministic native-physics paired-history construction in `lstm_blind_turn_necessity.py`, with both its turn-only and probe/glimpse cases. Noise is disabled **only for this controlled information audit**, as in that existing assay; noisy native navigation remains the training task.

For each pair, distinct visible/turn histories end at the same actual interior position, goal snapshot and zero motor state, with a common final action suffix. In the probe version, calculate starts from the genuine forward displacement to reach one common endpoint; retain the existing sub-1e-5 m rounding-correction record. At the primary decision require byte-identical complete 1,287-entry student inputs, including the full saved goal, action and reward. A common ordinary current vector removes any stale `mDir` leak. Check the last three inputs, all motor fields and event age too. The first-input erased students must produce identical distributions under identical sampling uniforms.

The full-vision teacher is evaluated on those same actual histories. **Root revised this preflight to descriptive only: no first-update progress threshold and no scientific pass/fail gate.** Pairwise Jensen–Shannon divergence is the minimum average forward-KL mismatch of one common memoryless action distribution; also compute generalized JS over each exact full-input equivalence class. Retain TV, actual six-action first-update progress, the common-action ceiling and descriptive goalward turning alignment. These are evaluation statistics, never labels, rewards or executed oracle controllers. A useful turn may have zero immediate translation. Each case therefore also receives one fixed 30-update noise-free native full-vision teacher continuation, with shared action uniforms within pairs, first-hit termination of scoring and preteleport positions. This is controlled teacher utility, not a later-horizon oracle ceiling. All 128 pairs per mode and model remain included. Integrity checks must pass; any acquisition decision follows the complete descriptive results and separate root review.

The concrete **preflight** uses 15 visible observations / 14 actual left actions, a 14-action left-versus-right prefix, an optional four-forward probe with a separate endpoint cue observation, and eight actual common left actions before the first choice. Eight ordinary observations follow the cue, including the first-choice input. Initial headings are prescribed using the native motor integral so final phases are antipodal; fixed 14-step opposite turns alone are not claimed to give exactly 180°. See the standalone preflight source and tests for exact timing. The archived source episode time and native 1,350-update cap are preserved. This controlled information audit is not silently substituted for the proposed varied-duration training schedule.

**Bounded learner.** If separately approved after the full descriptive preflight, propose the same small budget as the successful acquisition pilot: 16 environments × 90-update whole unrolls × 180 optimizer updates, or 1,036,800 native physics frames per population. One complete event is admitted per unroll, only after discovery and when its worst-case 57 updates fit within both the unroll and episode; retain the existing maximum eight events per episode. Three fixed 60-update blocks use suffix ranges 4, 4–8 and 4–15; this guarantees at least three ordinary post-cue suffix inputs before free choice. Teacher-action mixture probabilities are 0.5, 0.25 and 0; forced actions always override the mixture. Draw plans, action uniforms, cue coins and noise from independent private streams. Do not train on the preflight or evaluation bank.

The loss is mean forward KL from teacher to student **on policy-controlled decisions**, including each ambiguous choice and subsequent native navigation; forced decisions have zero direct KL weight but retain full BPTT from later choices. No angle, velocity, goal-coordinate, ring, decoder or entropy objective is added. Record choice-window KL separately from all other KL, plus every active loss count. The full event is inside one BPTT graph; no cue-to-choice truncation is permitted. The maximum is 180 updates and 1,800 monotonic seconds for the acquisition loop, with read-only qualification/final analyses separately timed and budgeted. No extension, cloud use or alternative initialization is proposed. This cap convention differs from the completed pilot's cap including evaluation and must be accepted explicitly before freeze.

**Fixed before/after tests and mechanism.** Retain the original and all three stage endpoints; analyze only original and fixed final as the primary comparison. On the sealed paired bank measure native cue, ordinary cue, rotated ±60° cue, erasure immediately before the cue, erasure immediately before the first choice, and erasure before every choice. Include the corresponding visible scheduled-erasure reference and exact Grid shams. All branches use the same physical histories, pulse endpoint, motor tape and common suffix until policy control starts. Compare first-choice distribution/progress exactly; compare three-choice paths only on matched physical clocks, with hit/termination recorded. For repair, contrast pre-cue erasure followed by native versus ordinary cue, then withdraw the cue; erasure at choice must abolish any information carried through recurrent state. Wrong-cue effects must track the measured travel rotation, rather than a substituted body angle.

Also retain 16 native held-out episodes per model for seen, modified-event intact, modified-event ordinary and modified-event state-erased conditions. Scores before discovery, forced-event rewards, the three blind choices and subsequent visible navigation are separate. Both fixed finals receive the existing direction-memory geometry screen irrespective of behavioral success. Useful history could be a counter, Cartesian estimate or another nonlinear recurrent computation; a ring claim requires the already established persistence, broad transverse recovery and predictive-cue repair tests in that learned state.

**Reuse and small verification scope.** Reuse `native_policy_distillation.py` for KL, frozen tensors, actual shared teacher/student history and replay; `rl_blind_reorientation.py` for event inputs, braking and held-code semantics; and `lstm_blind_turn_necessity.py` for the alias audit and native action ceiling. New files only. Required new checks are exact native/teacher initialization identity, all-column alias/cue masks, actual motor/brake and terminal timing, an unbroken cue-to-choice gradient, exact stored-input replay, and one real nonzero recurrent update. No new large validation framework is needed.

This is online policy distillation motivated by [Rusu et al.](https://arxiv.org/html/1511.06295), with learner-visited histories motivated by [Ross, Gordon and Bagnell](https://proceedings.mlr.press/v15/ross11a.html). It is not the full dataset-aggregation algorithm or an angle-supervised integrator. Across-population learning differences still mix different teachers and pretrained weights; within-model cue and state interventions carry the causal comparison.
