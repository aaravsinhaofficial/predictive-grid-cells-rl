# Counterbalanced static readout of the saved turn histories

This is a prospective exploratory readout, specified after the saved paired-history analysis exposed a correlation between prefix action and heading half-circle. The original geometry collection already contains a separate fixed LEFT prefix and fixed RIGHT prefix over the entire circle. This analysis uses all of those histories, without collecting recurrent trajectories or training a model.

The fixed cohort is both populations, original/clean/noise endpoints, all 16 contexts, both turn-only and probe-glimpse histories, both fixed prefixes, all 128 headings, and native/ordinary/pre-cue-reset-native/pre-cue-reset-ordinary branches. This gives 1,536 neural families and 196,608 phase rows. Exact Grid and turn-only substitution shams remain explicit rows, with their original archive aliases. Necessary-geometry gates and recovery outcomes do not select cases for this readout.

The actor reads `left/baseline_states.npz:t8`. Time zero is the state after the final native probe-cue input, or final turn-prefix input. Eight subsequent common LEFT observations produce the post-input state used for the first choice in the paired study. The actor receives that saved hidden state directly; it does not process the first-choice input a second time. Cell state remains archived and is checked against shared paired cases but is not an actor input.

The native physical counterfactual uses the recorded endpoint, actual choice heading, unchanged last-travel direction and original episode clock. The explicit choice brake sets forward, side and rotational motor velocities to zero. A single noise-free native update for each of the six actions produces projected goalward displacement and body-goal angle-error change. This is computed once for each of the 128 physical families and reused across endpoints and cue/reset branches. Any goal hit, wall contact or native time-limit event fails the physical check; it is retained as an incomplete run, never silently excluded or converted into teleport progress. No adaptive policy rollout is performed.

Before reporting completion, every family is checked against the previous paired data at its eight shared angles. Labels come from all 14 recorded prefix actions and input one-hots, not row parity. Angle matching is explicit. The full input comparison retains exact goal/action/reward fields, with declared float32 arithmetic bounds only for CNN/current-code components. The full-circle first-choice input must be byte-identical across prefixes and modes within each context. The four trained endpoints retain their respective population’s original actor bytes. Each geometry checkpoint, preparation manifest, original prefix replay record and paired raw artifact is hash-bound to its completed parent summary.

Numerical provenance thresholds are declared in the draft protocol before readout scores: heading 3e-5 rad; endpoint 1e-6 m; travel-direction components 3e-5; embedding 1e-5; current code 3e-5; hidden state 1e-4; cell state `1e-4 + 1e-5*abs(reference_coordinate)`; centered actor logits 1e-3; probabilities 1e-4; single-action projected progress 1e-7 m. Exact observed differences and the componentwise bound on shared-case expected-progress differences are saved. These are compatibility checks between float64 archived geometry recurrence and float32 paired recurrence, not effect-size thresholds or permission to interpret effects below numerical uncertainty. Failed comparisons retain their cases and mark the entire analysis incomplete.

Primary summaries show expected signed goalward displacement under the static policy, the same quantity under one phase-averaged policy per fixed-prefix family, their difference, the best common-action one-step value and antipodal action-distribution TV. Body-goal and turn-weighted alignment are descriptive auxiliaries; native strafing remains a valid action. Every prefix is shown separately and with equal weight in the full counterbalanced cohort. The averaged policy is a mathematical counterfactual, not an actual state erasure. No continuous-memory, ring or causal reliance claim follows solely from a static readout.

Only synthetic arithmetic, timing and corruption tests may execute before independent review and source/protocol sealing. The parent agent owns the seal and actual readout launch. No scientific score has been computed by this implementation step.

Per-phase states, probabilities and physical scores are stored losslessly in compressed NPZ artifacts, with the physical bank in PT files. Aggregate JSON/CSV contains no per-phase result lists. The full shared-angle audit is a separately hashed compact JSON; every artifact and all 196,608 phase rows remain available for the release archive.
