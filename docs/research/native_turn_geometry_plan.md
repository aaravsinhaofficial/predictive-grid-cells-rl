# Actual turn-history geometry: prospective design

This is a new assay of the actual controlled navigation histories used by the teacher and memory tests. It is not a reanalysis that changes the criteria of an earlier negative study. No original-policy geometry outcomes may run until the implementation, synthetic controls and protocol are reviewed and sealed.

**Cohort.** Use all 16 frozen episode contexts in each population. In every context prepare 128 equally spaced physical phases under a completely LEFT fixed prefix and, separately, a completely RIGHT fixed prefix. Each tape is continuous around the entire phase circle. The earlier interleaved antipodal pairs are behavioral data, not a continuous neural curve. Include both turn-only and four-FORWARD probe histories. This gives 128 dense physical input families across both populations. A static native-clock audit confirms every fixed context has at least607 updates remaining (Grid minimum620), exceeding the104 updates required for the longest physical preparation/diagnostic; all original1350-update episode caps remain in force. Original checkpoints and any prospectively fixed final acquisition checkpoints receive the same archived input families, while each checkpoint independently replays the complete original 32-slot prefix and terminal masks to obtain its own incoming state.

**Input and memory controls.** The first 15 observations are visible native observations, followed by the actual 14-turn prefix. Probe mode has four actual FORWARD actions and one native predictive cue at its common endpoint. Subsequent inputs use black RGB, the held ordinary current code, the original native goal snapshot and the true previous action/reward. Native versus ordinary changes only the predictive current entries at that one cue. Include pre-cue reset with native and ordinary cue; the ordinary reset branch must collapse exactly across phases. Turn-only cue operations and Grid cue operations are exact shams. A common zero-state control must collapse under all common future inputs. None of these controls erase the goal snapshot.

**LEFT regime and timing.** The reference is immediately after processing the measured probe cue; turn-only uses the last fixed-prefix input. The primary evolution is three actual LEFT updates (0.2 s). Eight updates reproduce the frozen preflight choice boundary, and 15 updates cover a one-second cue-to-state delay. Thirty and 60 updates are labeled two- and four-second extrapolation. Recurrent inputs remain common across phases throughout. LEFT rotates the body: any surviving phase family is under a turning drive, not a stationary zero-drive memory. Report neural polygon phase drift alongside the exact physical rotation.

**Secondary zero-angular-drive condition.** Starting from the eight-update choice state, prescribe the exact native FORWARD/BACK periodic motor solution, with vf initially negative and vs=vr=0. Execute one complete setup cycle before analysis, so every previous-action label is true. Held ordinary code and black RGB remove the within-cycle heading cue; goal remains unchanged. The B-section map is G_B after G_F; the F-section is the opposite section, with its own curve and map. Analyze the two sections separately at two and 14 recurrent updates, and at30/60 updates as extrapolations. Fixed two-section future outputs extend these windows by one update, to3/15/31/61. Report complete input equality across phases at both half-cycle sections, net physical displacement and body-heading drift, neural phase displacement and departure. A stationary angular memory requires little phase drift under this periodic drive; a circulating response is described as such. It is not a zero-input autonomous ring.

**Measurements without fitted coordinates.** Use the full512-dimensional h/c state, all256 hidden outputs, and all six actor logits after subtracting each row's common logit offset. No selected neurons, learned angle decoder, PCA plane or imposed circular fit defines a curve. Fixed future observations concatenate offsets0 and1 for hidden/actor outputs; the complete state is measured at offset0. LEFT hidden/actor evolution is window minus one update, so the latest observation remains exactly3/8/15/30/60 updates after the cue; full-state evolution is the complete stated window. F/B evolution remains even, with the second-section observation one update later. Report raw and h/c-RMS physical kick metrics; the RMS scales come from the reference state family and stay fixed. Centered output analyses subtract only the unperturbed family's common mean, preserving the same baseline for every perturbed sample. Full-state results and noncentered observable results remain separately visible.

**Staged computation.** Every dense family, control branch, observation, metric, section and fixed horizon receives closure, separation, phase transport and near-invariance tests. Keep all rows and every failed gate. Only a row meeting these necessary geometric gates receives the more expensive finite-normal test. This is a prespecified computational filter, not context selection. Retain the established thresholds: reference radius RMS at least1e-4; maximum edge at most10% radius; nonlocal separation10th percentile at least5% radius; at least5% radius retention; fixed-curve departure90th percentile at most5% radius; phase coverage at least80%; winding within0.1 of one; backward edges at most5%.

**Broad recovery.** At eight fixed evenly spaced phase indices, perturb both signs by2% of the reference full-state radius. Use16 seeded full-state random normals, one hidden-only random normal, one cell-only random normal, the full centroid-radial normal, and a cell-only centroid-radial normal, plus a tangent control. Remove the tangent from h-only and c-only directions within the same block, preserving block purity. Compare distance to the contemporaneously evolved full-dimensional curve, permitting legitimate phase shifts. Every direction must be observable initially in at least80% of its16 signed samples; flag any initially silent direction that later becomes observable as factor leakage. Tangent kicks must remain observable at the evolved endpoint too; erasing both tangent and normal is not selective recovery. A nomination requires each of the20 normal directions to have median normal gain at most0.5 and median normal/tangent gain at most0.5, separately in both physical metrics. Report every individual kick, p90/max gains and phase shift. A few fast directions cannot hide a persistent cell-state direction. Finite probes are evidence about the tested directions, not an exhaustive contraction theorem.

**Bounded physical qualification.** Preserve every nominal 2% perturbation result. For every geometry-qualified row whose nominal h exceeds [-1,1], regardless of recovery outcome, first test one shared smaller amplitude capped at90% of the smallest available two-sided h margin. Ignore coordinates with zero proposed displacement in that cap. If this construction has zero or unobservable size, use the previously audited bounded-pulse rule: clip only proposed h endpoints, leave c unchanged during clipping, then shrink all directions and both signs at each phase to the smallest realized scaled norm there. Save actual vectors, sizes, intended-direction cosine and tangent/normal components. Preserve h-only and c-only blocks exactly. Normals may have at most5% tangent contamination; tangent controls at most5% normal contamination. A zero/unobservable or incorrectly oriented physical construction is **inconclusive**, not a rejection of attraction. Physical qualification uses the first conclusive bounded construction; it never tries a second amplitude because the first conclusive one failed recovery. No separate projection or clipping after measurement is permitted.

**Natural history mismatch.** At the same physical angle, compare LEFT-prefix versus RIGHT-prefix states and future outputs in every context and cue branch. Report whether their difference decreases relative to angular separation. This is descriptive, with no new nomination gate. It tests whether the same angular variable converges despite different histories.

**Controls and subsequent causality.** A stationary ring under a genuine two-section affine action clock must pass; an action-locked point and a uniformly shrinking plane must fail. Check the correctly ordered two-step derivative against finite differences and verify phasewise input identity at both sections. Original and final checkpoints are included independently of behavioral outcome. A nominated family would next receive matched physical release and a native predictive repair pulse after a real BACK endpoint, using the actual backward travel direction rather than body heading. Such follow-up is not presumed successful and is not run by this geometry program.

No training, cloud instance or paid compute is part of this assay. Frozen earlier studies remain unchanged.
