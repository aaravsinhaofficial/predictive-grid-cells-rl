# Independent confirmation of learned memory-initialization map sharpness

This protocol is specified after inspecting all 32 exploratory dense-geometry results from seeds 2001–2016, and before training or viewing any new seed 5001–5016 outcome. The exploratory observation is a lower peak-to-median angular sensitivity in PGC models in 12 of 16 pairs (mean paired log10 ratio approximately −0.683). The new cohort is independent and is not pooled with that exploratory cohort.

Train exactly 16 paired Grid and PGC models, seeds 5001–5016. Keep the previously frozen heading-task and trainer sources unchanged: encoder width 256, unconstrained recurrent width 64, sequence length 128, batch size 64, AdamW learning rate 0.001, and exactly 6,000 updates. All remaining parameters retain the original fixed defaults. Use paired model initialization, spatial-code seeds and data/noise streams. Retain all final models, including poor performers. This is supervised heading estimation with no ring regularizer; navigation elsewhere uses a fixed controller. Training-source hashes are those in `heading_confirmation_sources.json`; the batch-launch wrapper is recorded but does not change the training algorithm.

The single primary endpoint is **learned memory-initialization map sharpness**. At physical position (0,0), start the hidden state at zero. Present the native deterministic spatial code and the same explicit initial heading cue for four steps, at zero angular velocity and speed. PGC native spatial rates depend on heading; ordinary Grid rates at this fixed position do not. Then apply 40 all-zero input steps (2 seconds), including the learned encoder's response to zero input. Disable all observation and recurrent noise. Analyze stored weights in float64. This measures the trained sensory-initialization-to-memory map, not recurrent weights in isolation or autonomous normal contraction.

For 1,024 uniformly spaced initial angles θ_j = 2πj/1024, calculate the exact state derivative ∂h/∂θ using an input directional derivative and the recurrent chain rule. Let s_j be its Euclidean norm in all 64 state dimensions. Rank circular intervals by endpoint state distance, resolving distance ties by ascending interval index. Select the four largest intervals whose circular index distance exceeds two from every previously selected interval. Bisect each selected interval 20 times, retaining the half with the larger endpoint state separation; an exact tie retains the left half. Evaluate the exact angular derivative at each final midpoint. The estimated peak is the maximum of the 1,024 uniform and four refined-center derivative norms. The denominator is the conventional NumPy median of the 1,024 uniform derivative norms (the average of the two middle values). The primary scalar is log10(max(peak,1e−12)/max(median,1e−12)). No normalization by state radius is part of the primary.

Save absolute peak and median sensitivity, peak angle, every sampled derivative, state radius, endpoint closure, readout amplitude, circular coverage, decoded heading error and decoded angular-derivative distribution. A state radius or median sensitivity below 1e−8 is explicitly flagged as degenerate, and any readout amplitude below 1e−8 is flagged as unreliable. Such models remain in the primary calculation under the fixed 1e−12 floor and must not be described as superior rings. Report how many models encounter either numerical floor. Nonfinite results are computational failures to investigate and report, never grounds to replace or silently exclude a seed. Verify the derivative propagation against independent automatic differentiation at fixed quarter-circle angles and at the estimated peak, without selecting new analysis angles based on condition differences.

Prespecified descriptive controls repeat exactly the same sharpness calculation (a) immediately after the fourth native cue, before blank recurrence, and (b) after four ordinary spatial-code inputs plus the same explicit initial heading cue for both trained populations, at both cue end and after 40 blank steps. Native Grid and ordinary-input Grid must match exactly. Ordinary initialization is an input intervention for a PGC-trained network, not its native operating condition. Report native sharpening during blank recurrence as the after-minus-before log sharpness. These controls help distinguish an uneven sensory initialization from its subsequent recurrent transformation, but are not additional primary significance tests.

For inference, pair models by training seed. The single primary contrast is the mean across 16 seeds of PGC minus Grid log sharpness after native initialization and 40 blank steps. Test this contrast with a two-sided exact paired sign-flip test enumerating all 2^16 sign patterns, using the absolute mean as the statistic and including equality. Report the mean difference, a two-sided 95% paired Student-t confidence interval (15 degrees of freedom), all 16 paired values, and optionally 10 raised to the mean difference as the geometric-mean sharpness ratio. There is one primary test, with α = 0.05; no additional family correction is required. Do not inspect partial p-values, stop early, add seeds after viewing outcomes, or exclude poor models. Descriptive controls and geometry are labeled as such and are reported regardless of whether the primary result favors PGC.

Freeze this protocol and `scripts/evaluate_heading_geometry_confirmation.py` with their training dependencies before cloud launch. Keep their checksums in `heading_geometry_confirmation_sources.json`. Later aggregation and figures must implement this fixed definition. This endpoint can support a difference in learned memory-map organization. It does not by itself establish global ring topology, longer autonomous memory, stronger transverse stability, or that this geometry mediates navigation performance.
