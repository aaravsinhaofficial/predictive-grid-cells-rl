# Exploratory dense full-state geometry cohort

Specified after finding sharp hidden-state transitions in the preselected first seed (2001), and after densely testing the first subsequent PGC candidate (2002). This is explicitly exploratory and does not change any primary endpoint, frozen evaluator, training run or cohort inclusion rule.

Evaluate all 16 Grid and all 16 PGC final checkpoints, seeds 2001–2016. Retain every model. Use the existing four-step native initialization at position (0,0), followed by 40 blank steps, without changing the network or training. Use float64 diagnostic arithmetic from the stored weights. Evaluate a uniform grid of 1,024 initial angles per model; preserve the independent 4,096-angle seed2002 reference and seed2001 branch audit.

For every uniform angle, compute the exact derivative of recurrent state with respect to initial angle by input JVP and recurrent chain rule. Check the implementation against independent finite differences at 16 fixed phase indices. Report the full-state curve, endpoint closure, angular derivative norm, decoded phase monotonicity, heading accuracy and coverage. Compute all 1,024 full-state Jacobians, slow-mode alignment to the exact tangent, and the projected normal-subspace spectrum. No median statistic may substitute for the reported extrema and per-phase rows.

Refine the four largest nonadjacent initial-angle intervals by 20 adaptive bisections each, choosing the half with the larger full-state separation. The nonadjacency rule excludes indices within two grid intervals of an already selected interval. Record state and input separation at every resolution. At each refined center, calculate the exact state derivative, decoded derivative and full-state spectrum again. This probes the narrow transitions missed by sparse, phase-uniform sampling; it does not assume a literal mathematical discontinuity in finite-step tanh dynamics.

For 10%-radius tangent and normal disturbances, measure every uniform initial phase after one and five seconds of common blank input. Normal distance uses the dense time-matched state curve. An accelerated nearest-segment search is checked against exact global projection at 64 fixed phase indices and falls back to exact projection if the discrepancy exceeds 1e-8. Preserve per-phase distributions, radius retention and heading error, including phases with poor retention.

Report continuous results and all seed identities. For descriptive counts, separately report whether any sampled normal-subspace eigenvalue has magnitude at least one, whether any sampled decoded angular derivative is nonpositive, and the largest state-derivative amplification relative to that model's median. These are diagnostic properties, not a new pass/fail definition of a ring. Sharp transitions, local transverse attraction, circular readout and a globally smooth approximate ring are distinct findings.

Use at most two local workers with two Torch threads each; prefer one while other evaluators remain active. Estimate runtime on the first new run. This cohort is not pooled into the locked primary significance family. The first-seed geometry figure remains in the report; the selected seed2002 continuous-loop figure must be labeled as an exploratory example, not substituted as an unbiased population illustration.
