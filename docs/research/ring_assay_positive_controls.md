# What the ring assays already recognize

Read-only review, 6 November 2026. Existing controls test actual nonlinear dynamics, including rotation and recovery after perturbation. They are more than drawings of circular states.

- [test_lstm_heading_curve_flow.py](../../tests/test_lstm_heading_curve_flow.py): `test_true_rotating_ring_has_invariance_and_radial_recovery` checks the production full-state invariance/recovery primitive on an attracting rotating circle. `test_shrinking_linear_plane_is_not_radially_attracting_ring` distinguishes radial recovery from uniform contraction; `test_closed_folded_line_fails_nonlocal_separation` rejects a folded line. This positive test checks the primitive's measurements, not the entire checkpoint-to-candidate pipeline.
- [test_lstm_endogenous_observable_flow.py](../../tests/test_lstm_endogenous_observable_flow.py): `test_known_ring_times_shared_drift_passes_centered_observable_control` passes the unchanged centered candidate conjunction despite a shared drifting coordinate. `test_shrinking_plane_sampled_on_a_circle_is_not_a_ring_factor` and `test_output_silent_circle_fails_observable_kick_guard` reject contraction and invisible output.
- [test_lstm_actor_logit_observable.py](../../tests/test_lstm_actor_logit_observable.py): `test_actor_null_phase_dependent_spectator_removed_without_fitted_map` passes the exact future actor-score map while the all-hidden map fails. `test_contracting_cartesian_memory_and_vanishing_scores_do_not_pass` guards against Cartesian contraction and vanishing scores.

These support sensitivity to an attracting circular factor, including some unrelated hidden activity. Fixed horizons, state metrics, radial perturbations and observable-amplitude gates still define the class being tested. A substantially warped or slower learned manifold can require a different, prospectively specified assay.

The [official Ságodi repository](https://github.com/catniplab/back_to_the_continuous_attractor/tree/22beac30891ab2f321af2c2308dfc8f62ac56dc0) was inspected at commit `22beac30891ab2f321af2c2308dfc8f62ac56dc0`: its complete 18-file tree contains no checkpoints, and its release list is empty. Although its description mentions pretrained models, `lstm.py` loads author-local `model_*.pth` files. Its standard PyTorch LSTM exposes both hidden and cell states, so an adapter is feasible if weights become available. No published trained-LSTM positive benchmark was executed here; no models, thresholds or frozen sources changed.
