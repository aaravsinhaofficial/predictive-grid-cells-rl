**Prospective recommendation: train useful memory while heading is stationary, using the existing forward/backward action pair.** This is a conditional design review. It changes no current run, source, threshold or endpoint, and authorizes no further experiment before all four current outcomes are reviewed.

The useful precedent is Hawes and Nolan’s PPO navigation study: networks trained with stopping periods maintained location during a zero-speed test, whereas a no-stop training variant lost location. Their stopped representation was approximately a line attractor. The transferable idea is to train the regime in which memory must persist. Their vanilla RNNs required plasticity across network components; this does not guarantee the same result from our fixed-head LSTM continuation. [Hawes & Nolan, 2026 preprint, Supplementary Fig. 7 and Methods](https://arxiv.org/abs/2609.35207).

**Smallest task change.** Retain the native maps, six actions, goal snapshots, visible entry, two forced-turn blocks, four-step movement probe, frozen full-vision teacher, choice/control KL weighting and three blind policy choices. Replace the post-cue LEFT delay with an even number of actual FORWARD/BACKWARD actions. A fixed curriculum of 2 cycles, then 2–4, then 2–8 cycles would closely match the current delay range; the longest event is 58 updates and still fits a 90-update gradient window. Draw cycle count independently of heading, goal, cue type and eventual performance. Treat the first full pair as the truthful setup cycle, not an invented previous-action label. All delay actions retain gradients from later choices but receive no direct action-imitation loss. No angle target, circular embedding, selected-neuron loss or ring architecture is supplied.

The exact two-step motor solution starts with forward speed −a, lateral/rotational speed zero, where a = vmax·k/(2−k) and k = 1−exp(−dt/τ). The first FORWARD and subsequent BACKWARD steps return position and motor state, while heading stays fixed. This is already checked by [the native physics diagnostic](../../scripts/check_native_forward_backward_cycle.py). **Motor noise must be disabled during this controlled delay:** the real environment otherwise adds hidden rotational and lateral disturbances even on F/B actions. With black RGB and held code, a student cannot observe those disturbances, whereas its teacher can. For a clean heading cue, disable motor noise from the existing pre-probe brake through the delay; restore ordinary navigation physics outside that declared window. A version retaining motor noise tests partially observed tracking, not exact stationary-heading memory.

**The action clock must contain no heading answer.** Use the same F/B tape across heading comparisons, with no heading-dependent release time or phase reset. Hold the entire ordinary current code through both half-cycles, not just at return points: the approximately 3 mm intermediate displacement would otherwise reveal orientation. Keep RGB black, goal snapshot fixed and previous-action labels truthful. Abort or retain explicitly marked interrupted cases after wall contact, reward or episode reset; such events break the common-input delay. At a release boundary, brake before the final observation if using the existing first-choice physics convention, and process that observation exactly once.

**Preserve both populations’ legitimate information.** After a straight forward probe, the predictive code reports measured travel direction. Ordinary grid cells can also reveal that direction from the difference between entry position and endpoint position if the RNN remembers the entry. Keep that history in both arms; do not erase it during acquisition to manufacture a predictive advantage. The predictive code is a potentially easier current cue, not the only angular-information route. With sideways motion, residual rotation or noise, travel direction and body heading differ, so save their actual relation rather than substituting body heading for the native code’s direction argument.

At a BACK return section, measured travel is opposite body heading. A repair cue there has the advantage of a common physical position across headings. Use that actual backward sign and the true BACK label. If acquisition only supplied forward probe cues, report backward repair as a polarity-generalization test; alternatively, prospectively include equally sampled forward/backward probes for both populations. A refreshed ordinary code at a FORWARD half-section is not a no-heading control when its position itself varies with heading. Match complete physical position, pre-cue history and recurrent disturbance before contrasting correct, ordinary and rotated predictive cues. Cue-conflict experiments are motivated by biological heading-circuit work, not evidence already obtained in this LSTM. [Basnak et al., 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12321575/).

**Specific gates that can refute the proposed mechanism:**

| Question | Required observation and interpretation of failure |
|---|---|
| Is useful memory actually demanded? | At fixed context and release phase, complete student inputs match across headings while teacher distributions differ and useful physical actions exceed the common-action reference. If current inputs identify heading, repair the task before learning. If the teacher supplies no useful angular distinction, this is not an informative acquisition test. |
| Does the agent use retained information? | On new contexts, continuous headings and independently varied delay lengths, intact history supports useful choices; matched choice-state erasure removes that advantage. Preserve the visible erasure reference. A few successful action categories alone cannot identify a continuous ring. |
| Is a continuum retained? | Under each two-step section map, a full phase-coherent state family remains separated with little drift relative to unchanged body heading. Six clusters indicate categorical memory; a common trajectory indicates action locking. Keep both full h/c and fixed hidden/actor observations. |
| Is the family attracting? | Bounded perturbations off the family return while tangent differences survive. If both disappear, the mechanism is contraction toward a point. Zero, invisible or badly reoriented kicks are inconclusive. Require the already specified broad h-only, c-only and mixed controls. |
| Is predictive input corrective? | From the same disturbed state, correct native cue improves phase accuracy and subsequent native choice relative to ordinary replacement; rotated cues move the represented direction as predicted. Withdraw the cue before testing persistence. A change in activity amplitude alone is not angular repair. |
| Is the ring intrinsic or periodically driven? | Analyze B and F sections separately. Also clamp each corresponding complete input and test retained phase and recovery under the resulting autonomous neural maps. Survival only under the alternating tape supports a driven memory mechanism. Claim an intrinsic recurrent ring only for the autonomous condition actually tested. |

A periodic drive can support multiple discrete phase-locked attractors, so a loop in time is not the same object as a continuous circle of memories. The Poincaré map must preserve different remembered headings, not merely repeat the F/B clock. [Pals, Macke & Barak, 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10868787/).

Keep online cue repair separate from learned attraction. Once complete state and future input are identical, the same LSTM has the same next-state dynamics regardless of which cue occurred earlier. A predictive cue can move state into a useful basin; predictive training can change the learned basin. Those are distinct causal comparisons. A positive future continuation would reveal an acquired mechanism in this navigation agent; explaining the original 1B-frame performance gap still requires that mechanism in the original checkpoints.
