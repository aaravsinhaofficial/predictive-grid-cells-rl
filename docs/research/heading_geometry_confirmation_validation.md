# Independent geometry endpoint validation

The primary protocol and evaluator were frozen before launching new seeds 5001–5016. Their checksums are in `heading_geometry_confirmation_sources.json`. Validation used previously observed exploratory models only; it did not inspect new replication outcomes.

The new evaluator reproduces the earlier dense diagnostic's peak angular state sensitivities exactly: 125,708.43981673683 for Grid seed2001 and 20.592597694859286 for PGC seed2002. It also reproduces the conventional median of all 1,024 uniform derivative norms. The new primary uses NumPy's average of the two middle values; the earlier exploratory ratio used Torch's lower median. That small implementation distinction is explicit in the new frozen definition.

Independent automatic differentiation through the full state trajectory agrees with the propagated derivative at the quarter-circle test angles and estimated peak: maximum relative errors are below 7×10⁻¹⁶ in these reference models. The sharp and smooth examples exercise different sensitivity regimes. The ordinary-input Grid control reuses the native Grid calculation because both call exactly the same `condition="grid"` input function; this is an identity of the experimental inputs, not an additional independently observed replication.

An independent code review found no blocking error in the angular derivative chain rule, float64 spatial-code conversion, circular adaptive intervals, interval separation, tie rules, median definition or degeneracy policy. The recurrent layer has no bias, so applying it to the tangent is the correct derivative. Input rows are independent, so the vectorized angular JVP gives each row's own-angle derivative.

The endpoint remains an **estimated peak** over a fixed uniform grid and four adaptively refined intervals. It does not guarantee the mathematical supremum over every possible initial angle. It measures the learned native initialization-to-memory map; cue-end and ordinary-initialization controls describe sensory and recurrent contributions separately. The final aggregator requires exact frozen source hashes, the independent confirmation stage, all 32 unique fixed-budget checkpoints, and all 16 pairs before calculating the one primary sign-flip p-value. Numerical checks of that test give 2/65,536 for sixteen equal nonzero differences and 1 for balanced or all-zero differences.
