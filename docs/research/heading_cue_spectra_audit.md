# Independent audit of cue-conditioned spectra

The implementation in `scripts/evaluate_heading_cue_spectra.py` correctly separates input effects from differences in recurrent state. Each blank/native/ordinary comparison starts from exactly the same full state and empirical tangent. The recurrence and readout weights stay fixed. The two reference-state families—cue-free and native-anchored—are reported separately.

The exact phase gradient for affine output y = Wh + b is `(y₀ W₁ − y₁ W₀) / ||y||²`. The readout bias correctly affects y and its denominator. The phase gain uses this gradient at the next state in the numerator and at the initial state in the denominator. It is a one-step gain in the trained phase coordinate, not an eigenvalue. Tangent normalization/sign and rotation or uniform scaling of the output coordinate do not change it.

Seven independent tests pass in [test_heading_cue_spectra_audit.py](../../tests/test_heading_cue_spectra_audit.py): gradient agreement with autograd for a biased readout, fixed-input Jacobians, circular finite differences, tangent scale/sign invariance, readout rotation/scale invariance, the input-dependent tanh-gain identity, and a known system with separate radial and phase contraction.

The real-checkpoint audit in [audit_heading_cue_spectra.py](../../scripts/audit_heading_cue_spectra.py) independently checked every phase in the pilot: 72 headings × six contexts × two reference states × three inputs, or 2,592 phase conditions. Maximum phase-gradient disagreement was 1.1×10⁻¹⁶; maximum phase-gain finite-difference disagreement was 6.0×10⁻¹⁰; maximum full-state directional-derivative disagreement was 2.6×10⁻¹¹. The minimum decoded amplitude was 0.771 before and 0.699 after an update, and every phase was resolvable. [Saved audit data](../../results/ring_heading/encoder_pilot/cue_spectra_independent_audit.json).

At the same state, the input-dependent change in the full Jacobian is exactly `leak × diag(change in tanh slope) × recurrent weights`. The pilot also shows smaller phase-direction response when the pre-update phase gradient is held fixed, which helps separate changes in the recurrent map from changes in readout-coordinate geometry. This is consistent with the cue changing the network's local sensitivity through its activation slopes.

Interpretation: without a cue, the learned heading ring has a nearly neutral phase direction. A predictive cue makes the cue-consistent phase locally stable. With a fixed cue, this means pinning one phase, not preserving a continuum of equally stable phases. The separate cue-free memory analysis supports the learned-ring claim; the present assay explains how input pins it.

Two qualifications matter. `normal_largest_singular_value` measures the normal-to-normal projection at the current tangent; it excludes normal-to-tangent leakage and should not be described as the growth of all transverse perturbations. Instantaneous eigenvalues at a non-fixed operating state do not substitute for finite-time perturbation recovery. Full singular values and the separate trajectory tests are therefore useful complements. For the all-model analysis, report readout amplitude and valid-phase fractions so poorly resolved phases remain visible rather than silently contributing extreme gains.
