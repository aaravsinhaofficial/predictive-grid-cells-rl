The proposed mechanism is that the relationship between current and forward-shifted spatial patterns supplies a direction signal that can correct a drifting recurrent memory. Recurrent weights were trained to estimate heading, without a ring architecture or a loss enforcing circular states; navigation then used that estimate through an identical, fixed controller. This demonstrates a supervised recurrent estimator coupled to behavior, separate from training a navigation policy by reinforcement learning. Here the predictive code uses an independent noisy movement-direction measurement, rather than the RNN's own estimate. The explicit-heading control supplies that same information directly, testing whether the benefit belongs to directional information rather than a unique property of predictive encoding. [Task and controls](ring_heading_protocol.md)

Stabilization here means anchoring the remembered direction with continuing input. Dense sampling reveals heterogeneous geometry: an audited model supports a smooth closed state loop with transverse contraction across the sampled phases, while another contains sharp full-state transitions largely invisible in its heading readout. A new 16-pair replication did not confirm a consistent PGC reduction in memory-map sharpness (exact p=0.110). Across the original 16 PGC models, a fitted intrinsic drift plus one cue-dependent sine term explains 78.6% of held-out phase-field variance and predicts recovery with 6.89° mean error. That successful reduced description does not require a single smooth ring in every network. Direction-conditioned state substitutions produce a 15.58 cm mean early path change in Grid agents, versus 2.36 cm in PGC and 0.90 cm with explicit heading. Near sharp transitions, these substitutions can also change readout-null state components; they are not universally pure phase perturbations. The results support useful correction of recurrent memory errors through an independent directional reference. They do not imply uniformly stronger autonomous memory: normal return is faster in Grid networks at one second, and after 32 seconds without input Grid/PGC heading errors are 31.6°/44.5°. The raw-input architecture also contracts disturbances under PGC input while retaining substantial direction error, showing why convergence must be assessed alongside accuracy. A preview generated solely from the network's own drifting estimate lacks the independent reference; contraction can instead reflect locking onto an inaccurate state. Accuracy, full-state geometry, finite-time recovery and behavior must therefore be read together. The original reinforcement-trained LSTMs supply a related but distinct mechanism. Predictive goal input protects selected stored-state directions through forget-gate feedback, while restoring predictive influence to the candidate update and output gate recovers much more of the navigation loss. These interventions separate memory protection from the action computation that uses the cue; the two assays do not yet show that the measured protection itself causes the behavioral improvement. Nor have the protected LSTM directions been identified as the heading ring studied here. The original directional-memory screen instead emphasizes dependence on continuing input. The shared lesson is that informative spatial input can alter the network's local error propagation and useful computation without changing its weights during evaluation. The new heading model supplies a concrete phase-anchoring example of that principle, while transferring the same ring-specific explanation to the original agents remains a separate causal test.
