# Minimal six-action observation test

Draft only. No model, environment or query outcome has been run for this proposal. This is conditional on the currently sealed dense study finding no candidate. A dense candidate instead receives its planned causal validation first. The completed full-state and fixed-observable results remain unchanged.

The method is defensible as a new **fixed observation of the same stored state**. It is not a new retention dynamic. From an independent copy of a saved state, execute one truthful native action, supply its actual previous-action label and read the next actor probabilities. Repeat for all six actions in the fixed native order. Concatenate the six six-action distributions into one 36-dimensional response. A query may reveal or rewrite memory; it must never be inserted into the retention trajectory.

## Fixed cohort and timing

Use only the two original 1B checkpoints and their existing 128-heading archives: all 16 contexts, both coherent LEFT/RIGHT prefixes, both turn-only/probe modes, and all four native/ordinary/reset branches. There are 512 named neural families, including exact shams. The archived alias map leaves 128 distinct Grid and 192 distinct PGC neural families; every alias remains in the denominator. No family is selected by earlier geometry, behavior or query response.

Use these existing archived states, without recomputing retention:

| Map | Reference | Retention updates | Extra measurement |
| --- | --- | --- | --- |
| LEFT | Original post-cue/prefix state | 2, 7, 14, 29, 59 | One query update |
| F/B, B section | Original post-setup BACK state | 2, 14, 30, 60 | One query update |
| F/B, F section | Original post-setup FORWARD state | 2, 14, 30, 60 | One query update |

These clocks match the previous hidden/actor screens: LEFT observations finish at 3, 8, 15, 30 or 60 updates from the cue boundary. F/B observations finish at 3, 15, 31 or 61 updates from their own section reference. The B and F references occur respectively 10 and 11 updates after the cue. Both section identity and absolute cue-to-observation time are stored. Retention and measurement time are reported separately. F/B retains its periodic-drive interpretation; LEFT retains its actual angular drive.

The primary profile is the complete, equally weighted **unscaled** concatenation of 36 probabilities. There is **no division by sqrt(6)**. If its Euclidean family radius is R, then R/6 is exactly the RMS variation of an individual action probability, averaged over headings, six queries and six action outputs. The primary absolute sensitivity floor is R/6 >= 1e-4 probability units (0.01 percentage points); this is a prospective numerical-visibility requirement, not inherited logit units or a claim of meaningful navigation improvement. All probability variances, antipodal TVs and absolute changes remain reported, including values below the floor.

Centered probability and centered-logit profiles are declared diagnostics; they cannot replace a failed primary behavior-facing screen. No selected neurons, fitted readout, learned projection, whitening, phase-dependent probe choice or unit-circle normalization. Existing all-hidden negatives remain separate. A new 1,536-dimensional six-query hidden profile is omitted from this minimal proposal: it adds approximately 8 GB and cannot supply the required policy relevance on its own.

## Physical validity before neural screening

Restore each physical reference from its saved metadata. At the cue/prefix reference the explicit brake has already zeroed all three motors, even when the last recorded probe observation has nonzero movement. LEFT has another brake after update 8. F/B uses the exact prescribed motor cycle, actual travel direction and separate F/B reference sections.

Reconstruct the unchanged retention physics only to validate each probe; the neural retention states come from the existing archives. For every declared anchor time, clone the physical state six ways and execute all six real native actions. Keep visual input black and current code held at the existing ordinary snapshot; keep the native goal code. Verify actual reward, goal state, termination and complete 1,287-dimensional query input across all 128 headings. Do not fabricate zero rewards or relabel an unexecuted action. No policy/environment clock is an extra RNN input; the actual clock still governs termination checks.

If any action lacks a common valid input at any required angle/time, retain the full affected case as physically unavailable, with its exact cause. Do not omit that action, replace its input or drop its context. Physics eligibility is recorded before applying the actor. The once-per-population/context/prefix/mode bank is shared across neural branches. Unused image rendering can be bypassed while leaving `ArenaEnv.step` physics/reward/reset logic unchanged; a synthetic comparison must verify identical physical outcomes with and without that bypass.

The recent paired-versus-circle rendering mismatch does not authorize any tolerance change. This proposal uses each existing coherent circle as supplied and does not claim byte identity with the separately generated 16-case paired history. Its own complete query-input equality must be exact. All current shared-density guards remain binding.

## Fixed screening and conditional validation

Apply the existing full-dimensional polygon, spacing, separation, phase-order, phase-coverage and near-invariance criteria to the primary probability profile. Keep their original dimensionless thresholds, all original angles, every time window and explicit finite-resolution failures. The absolute probability-visibility gate is explicitly defined above. Report physical phase transport relative to actual LEFT rotation or zero F/B heading change. The query index is never the angle coordinate.

Only qualifying primary profiles proceed to the existing eight full-circle anchors and fixed 20 physical normal directions plus tangent, both signs, raw and h/c-RMS metrics, including the established bounded-kick policy. The directions are the same 16 seed-fixed full-state random directions, h-only, c-only, full radial and c-only radial, followed by the tangent control. All 8 x 21 x 2 = 336 signed kicks per metric are retained. No favorable anchor, direction, sign, branch, map or time window is selected.

The underlying retention map stays unchanged. Set the initial response visibility floor to max(1e-8, 1e-4 * R/6), in per-probability RMS units. A kick is an observable normal when its distance from the response polygon divided by 6 exceeds this floor; it is phase-only when its total response change exceeds the floor but its polygon distance does not; it is invisible when its total response change is below the floor. A phase-only or invisible kick is not counted as transverse recovery. Retain its phase transport or future leakage test and mark transverse qualification inconclusive when required. Preserve the old recovery thresholds and per-direction accounting; never pool a slow c-only direction with fast h directions. No response-space direction fitting or new quotient search is part of this minimal batch.

Freeze these six held-out three-action sequences before any primary response is evaluated, using native labels LEFT=0, RIGHT=1, FORWARD=2, BACK=3, STRAFE_LEFT=4, STRAFE_RIGHT=5:

`(0,2,1), (1,3,0), (2,4,3), (3,5,2), (4,0,5), (5,1,4)`.

Every action appears three times across this finite set. Each sequence starts from an independent physical/neural copy; its complete truthful input tape must pass the same common-input checks. These are held-out equivalence/leakage challenges only. They are never appended to the discovery profile, and no two-action discovery-bank expansion is permitted. Failure cannot trigger a longer or selectively chosen query.

For a phase-only kick, project its initial discovery response onto the initial discovery polygon and retain that inferred **original physical phase label**. Its held-out response must agree with the baseline held-out profile at that same label. After retention, compare with the baseline that evolved from that original label through the unchanged map. Do not independently choose a better phase in the held-out bank. Invisible kicks use the original anchor's label. Thus a phase-only kick that implies a different phase or another response under held-out queries fails functional equivalence just as an invisible kick that becomes visible does.

Baseline held-out responses at an intermediate label are interpolated only between the two bracketing **observed response vectors**, not by inventing/interpolating an h/c state. For each held-out sequence separately, require the bracketing output edge divided by sqrt(6) to be <= max(1e-8, 0.10 * r_s); otherwise mark phase matching unresolved. Here r_s is that sequence's baseline per-probability angular RMS at the same retention time. Compare each six-action distribution in absolute per-probability RMS units with tolerance max(1e-8, 0.05 * r_s). Store every absolute discrepancy and the interpolation bracket. Each sign, phase and held-out sequence must pass; medians cannot hide a single leakage case. A constant held-out profile uses the 1e-8 absolute floor for both checks. A failed or unresolved required closure test prevents qualification and ends this branch rather than expanding the bank.

Primary phase sensitivity must remain nontrivial in actor probabilities under the stated absolute gate. Report its behavioral scale separately: actual action-distribution TV and signed goalward displacement relative to the phase-averaged policy, in native distance units, at matched physical query endpoints. This is a descriptive utility calculation rather than a new angle-fitting objective or a sufficient mechanism claim. A surviving pattern needs the prospectively specified finite-normal, held-out and pre-query state/behavior/cue-repair validation before a functional ring mechanism is claimed. A lack of retained policy phase sensitivity or a failed held-out closure ends this ring branch. Centered/logit-only sensitivity is not an adaptive rescue. No further continuation training or probe expansion follows a negative result.

Synthetic controls precede any model query: a circular memory silent during retention but readable by a common query; a shrinking plane; an action-locked point; a query-produced response without retained phase; and a direction invisible to the discovery bank but revealed by a held-out query. Tests must distinguish geometry nomination from genuine measured transverse recovery and from an inconclusive invisible fiber.

## Finite work and storage

The reference plus retention endpoints give 16 saved state arrays per distinct neural family. Across 320 distinct families this is 5,120 state arrays, 655,360 archived states and **3,932,160 one-update query responses**. Exact aliases require no repeated neural computation. The physical bank has 128 families × 16 anchor times × 128 headings × 6 actions = **1,572,864 one-action physical probes**, plus the short deterministic physical retention checks. No newly trained checkpoint is included.

The same `W_hh h + b_hh` term can be computed once for a state and reused across its six input drives. A float64 synthetic test must verify this factorization against six ordinary LSTMCell calls before use. The run must additionally compare the two calculations at all eight fixed phase anchors, at reference and maximum retention time, for every distinct family and map. Maximum absolute probability disagreement must be <= 1e-12; failure is a numerical/provenance failure, not a dynamics result, and no tolerance is widened. The primary 1e-4 visibility floor is eight orders of magnitude above this arithmetic limit. This factorization avoids six redundant recurrent matrix products without changing the model. Query states are processed a family at a time. Store the complete probability and centered-logit profiles, input hashes and phase metadata; approximately 0.4 GB of uncompressed profile arrays for the two originals, plus small physics/provenance records. Peak working memory should remain below 1 GB excluding loaded parent summaries.

Unbenchmarked planning estimate: approximately 10–25 minutes for both original screening cohorts on available local CPU capacity, with a fixed proposed hard cap of **1,800 seconds per population at one thread**. Hardware load can change that estimate. Synthetic-only timing can refine the estimate before sealing without changing scientific criteria.

Broad-kick, fixed held-out and matched physical utility validation has a separate fixed proposed cap of **3,600 seconds per population at one thread**, covering every qualifying primary family/map/window and both metrics. It is not a top-N or best-case selection. Its workload depends on the number of qualifying cases, so no precise completion-time claim is made before outcomes. Maximum allotted time is therefore 5,400 seconds per population for this finite batch. Exceeding either cap retains all completed and pending case IDs, marks the cohort incomplete, and does not justify selective retries, omission of hard cases, a larger probe bank or a claim based only on early positives. All caps are sealed before any original-network response is observed.

Implementation should be one small new wrapper around the existing saved-state reader, exact LSTM equations, curve checker and perturbation helpers. This draft proposes no changes to any frozen source or protocol. Root owns the launch decision after the dense results and prioritization review.
