# Prior work and the contribution tested here

Literature checked on 5 November 2026. The mechanism should be described relative to the following work, rather than presenting learned rings, predictive grids or cue anchoring as new by themselves.

| Prior result | Relation to this study |
| --- | --- |
| [Ouchi & Fujisawa, Science 2024](https://doi.org/10.1126/science.ado4166) identified prospective spatial firing in MEC. Their measured forward shift averaged 22.5 cm, with substantial variation. | Motivates the supplied 20 cm spatial-shift code. The model uses an analytic population and an observed direction signal; it is not a simulation of the full biological circuit generating prediction. |
| [Zutshi, Leutgeb & Leutgeb, 2017](https://pubmed.ncbi.nlm.nih.gov/29333481/) proposed that grid-cell sequences can provide movement direction. | The broader grid-to-direction idea is precedent. Here, ordinary/predictive phase subtraction gives an explicit position-cancelling calculation, and learned sensory-drive interventions test its functional counterpart. |
| [Cueva et al., ICLR 2020](https://arxiv.org/abs/1912.10189) optimized recurrent networks for angular integration and analyzed compass/shifter organization. | An unconstrained RNN learning a direction-memory ring is an established modeling approach. The present question is how predictive spatial input changes that learned memory and navigation. |
| [Sorscher et al., Neuron 2023](https://doi.org/10.1016/j.neuron.2022.10.003) linked trained path integrators to computational and mechanistic accounts of grid formation. | Provides precedent for extracting a low-dimensional computational explanation from heterogeneous trained weights and activity. Our grid codes are supplied inputs, not newly emerged grid fields in the compass network. |
| [Ságodi et al., 2024](https://arxiv.org/html/2408.00109v2) analyzed approximate continuous attractors and slow memory dynamics. | Motivates measuring fast recovery across the memory set together with slow, heterogeneous drift around it. Finite-time analog memory need not be an exact continuum of eternal fixed points. |
| [Pak et al., 2026 preprint](https://pmc.ncbi.nlm.nih.gov/articles/PMC12871166/) linked prospective locomotion-related signals to recovery of head-direction attractor dynamics in restrained mice. | Closely related biological motivation. The current model specifically tests a spatially encoded direction reference, not that experiment's full sensorimotor or circuit mechanism. |
| [Shaikh & Assisi, 2025 reviewed preprint](https://elifesciences.org/reviewed-preprints/108142) modeled intrinsic and circuit mechanisms producing predictive grid coding. | Addresses generation of the predictive code. Our main learned-ring experiments address how a downstream recurrent consumer uses it. |
| [Clark, Abbott & Sompolinsky, Nature Neuroscience 2026](https://doi.org/10.1038/s41593-026-02452-4) related heterogeneous tuning and disordered weights to quasi-continuous attractors and underlying symmetry. | A visually obvious circular wiring matrix is unnecessary. Full-state perturbations and state-dependent Jacobians are more informative than looking for a literal ring in the weights. |
| [Sinha, Fasehun & Redman, 2026 preprint](https://doi.org/10.64898/2026.10.09.757963) reported predictive coding in recordings and path-integrating RNNs without an explicit predictive objective; preliminary lesions changed longer-timescale grid-population autocorrelation. | Direct project background. Those internally predictive units and their recurrent-output lesions are distinct from the supplied predictive inputs in the new compass task. An initial single-checkpoint exploration is followed by a ten-network replication with published cell classifications. Its prespecified modest-attenuation tests do not show a selective predictive-cell deficit. |

The contribution being tested is a connected causal account: **relative spatial phase supplies direction; a learned sensory pathway carries that information; its input-dependent nonlinear gains anchor a slow recurrent phase; and correcting that phase improves navigation.** The evidence includes prediction on held-out positions, targeted removal/restoration, random-direction controls, state perturbations and seed-level replication. The original reinforcement-trained square-arena LSTMs supply a separate gate-level result, rather than evidence that those agents already contain the same compass ring.

## Biological predictions

If a downstream direction-memory population uses the proposed mixed-phase comparison, disrupting the predictive-versus-current spatial relationship while preserving overall firing should alter its remembered direction more than an equal-energy disruption outside the direction-carrying subspace. Rotating the predictive displacement should rotate the anchored direction. Removing an independent reference should increase phase drift or bias while leaving short-time transverse recovery relatively intact. These are testable consequences of the model; they have not been measured in animals here.

## Data boundary

The Ouchi paper's availability statement points to the article and supplement; no new raw Ouchi recording analysis was performed. The Sinha preprint links the [Gardner grid-torus recording archive](https://figshare.com/articles/dataset/Toroidal_topology_of_population_activity_in_grid_cells/16764508) and its [analysis repository](https://github.com/Dynamical-Intelligence-Group/predictive-grid-cells). The present study does not treat those earlier biological analyses as newly collected evidence.
