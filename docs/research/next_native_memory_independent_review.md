# Independent review of a next native-memory study

**Design only, 6 November 2026. No implementation, model execution, training or cloud launch.** This is separate from every completed study. The proposed parents are the original 1B checkpoints, not the failed continuation endpoints.

**Recommendation: first use brief goal cues with normal navigation feedback and a longer action window.** This isolates goal storage while retaining the agent's familiar control inputs. Distance-progress reward is a defensible alternative acquisition objective, but it adds a second change whose benefit is uncertain with the current return estimator. Do not combine both changes in the first pilot.

The completed checks suggest two specific bottlenecks. Changing only the initial actor removed successful returns despite identical first-choice h/c and inputs. Retained actors mostly used right turns and right strafes; the saved-tape physical calculation limits that restricted repertoire in the two-second task. Longer navigation can address the latter without first teaching blind control or resetting the useful action readout. These findings concern this transfer task and one original seed pair.

**What has already been tested.** The [original goal-family pilot](../../results/original_goal_bearing_manifold/pilot/README.md) already varied saved goal messages around native histories and then withdrew them. About 70% of full-state goal separation survived one second in both populations, including ordinary-goal replacement within PGC. Refitted angular readouts remained accurate, while normal perturbations did not show the required preferential recovery. The [actual-pickup feasibility analysis](../../results/original_goal_circle_cue_feasibility/README.md) already found better geometric angle estimates at the predictive point: 19.4→7.8 degrees in Grid pickup histories and 19.9→11.9 in PGC histories. Those were geometric estimates, not actor decoding.

More decisively, the [earlier 5.0048M-frame goal-flash training pilot](../../results/ring_rl_goal_memory/README.md) already trained on circular goals with brief saved-goal cues. Search improved; post-cue h/c erasure cost only 0.31 score points in each population. At its original baseline, continuous cues gave scores 139.53/128.12 (Grid/PGC) over 90 seconds, versus brief-cue scores 66.72/59.53. Thus goal-circle input, brief-cue training and persistent goal traces are not new discoveries. The proposed added information is **stationary encoding without physical externalization, a single first-return trial, genuinely constant common delay inputs, and goal-specific state-to-behavior interventions**.

**One bounded proposal, revised after that prior evidence.** Retain the original 1B actor, CNN and LSTM exactly. Replace only the critic with the same archived fresh critic in both populations, avoiding transfer of the 90-second value scale; this does not affect baseline actions. Train all parameters with a fresh, recorded optimizer only after qualification. Keep six native actions, native FREE motor noise, maps, goal radius, sparse native goal reward and its existing learning clip, gamma .99, entropy 8e-5 and zero added recurrent noise. Set image noise to zero in this controlled task. No angle targets, ring loss, state architecture, selected seeds, or automatic competence-training extension.

- Use a common central start and a goal center at radius 0.75 m, with continuously sampled bearing. Draw incoming pickup direction independently of goal bearing and share each actual approach between populations. Obtain the saved code from an actual native boundary crossing toward the goal center, not a center pickup or an approach always radial from the common start. Then discard setup reward/history and reset pose, heading, travel direction, motors, previous action and reward to common goal-independent values. Room appearance and tapes are also independent of goal identity.
- First evaluate the **frozen originals without training**, with goal code continuously available during the same stationary wait and 90 free updates (six seconds). Require both to reach 192/256 targets on a new sealed bank, with all cases retained. The earlier 90-second results support doing this inexpensive qualification, but do not establish its six-second outcome. If either fails, stop this proposal before training; do not add another competence-training block.
- If both qualify, train three fixed blocks of 1,024 batches × 32 trials per model, using delay lengths 0, 15 and 45 updates. In every block show the saved goal for 15 recurrent cue updates, then zero all 512 goal inputs for delay and navigation. Preserve every block and judge the fixed last endpoint. This is a bounded curriculum choice, not an optimized or literature-established schedule. The pair receives 196,608 trials total, without an outcome-triggered extension.
- During cue and delay, explicitly immobilize the agent: no `env.step`, no chosen policy action, fixed pose/heading/travel direction/zero motors, `pa=-1`, `pr=0`. Repeat its actual clean native RGB/current code. LSTM and critic updates remain active; actor and entropy masks are zero. This disclosed task operation is not a seventh action. Then release the unchanged six-action native physics and fresh sensory feedback for 90 actions, ending at the first hit or timeout. Record recurrent wait updates separately from physical steps. The longest complete sequence is 150 recurrent updates, within the 160-update storage convention.

A suitable prospective final bank samples new continuous goal bearings with a fixed 45-update delay. Report all trials; compare continuous goal input, brief cue, no cue, post-cue h/c erasure, and wrong-goal cue. Use 167/256 brief-cue successes plus at least 39 lost after erasure as a descriptive useful-memory screen, matching the separate proposal; require goal-specific donor-state behavior as further causal evidence. Also retain erasure with a continuous cue to distinguish loss of retained goal information from general controller disruption. Six seconds permits goal-blind search: **the earlier two-second 50% certificate does not transfer**. Matched no-cue/erased histories measure this alternative directly, without declaring a new universal ceiling.

Varied pickup directions retain a concrete prediction from the original work. At center distance 0.75 m, a boundary point at radius 0.30 m can deviate in bearing by up to `asin(.30/.75)`, about 23.6 degrees. An ideal 0.20 m inward predictive shift leaves radius 0.10 m, reducing this to about 7.7 degrees. Actual crossing positions and velocity determine the exact values. The ordinary pickup is already inside the rewarded disk: predictive input may chiefly provide a safer inward target, rather than uniquely revealing the center. A mixed ordinary/predictive code also potentially conveys the incoming direction through their displacement. These are distinct hypotheses to test.

The code makes this separation plausible: [the renderer](../../code/env.py) reads pose and room appearance, not the unmarked goal. However, goal-dependent setup or spawn position, residual motors, travel direction, previous actions, room layouts and random draws must not carry goal identity into the delay. Use common stationary preparation and explicitly reset physical start variables after setup. While alive, keep previous reward zero, as in [the current collector](../../scripts/local_return_feedback.py); a first hit ends the trial. An external saved-goal cache may remain in the evaluator, but after withdrawal it must never enter the model. Native background inputs during the stationary delay are constant and identical across goal directions, so the LSTM recurrence is autonomous conditional on that background input. During FREE navigation, movement-dependent inputs can legitimately reflect earlier goal-informed actions; erase state before that movement.

**Why progress reward is not an automatic credit-assignment fix.** The current [returns/losses](../../scripts/local_goal_return_training.py) use complete-trial Monte Carlo targets. A potential term `gamma*Phi(next) - Phi(now)` with zero terminal potential sums to a state-only baseline; it does not add a new return preference. Ordinary distance decrease is different. For a free trajectory of T transitions,

`sum gamma^t*(d_t-d_(t+1)) = d_0 - gamma^(T-1)*d_T - (1-gamma)*sum_(t=1..T-1) gamma^(t-1)*d_t`.

It deliberately rewards a smaller final distance and earlier approach. If separately approved later, add `(d_t-d_(t+1))/(2*arena_half)` **after** clipping the native goal reward to its existing +1 learning value; do not reclip the combined reward. Use actual pre-teleport positions, signed progress, no forced/setup reward, and the actual distance at timeout. Never feed this distance signal through previous reward or any other model input. This would be a changed navigation objective, not policy-invariant shaping or an assured improvement in Monte Carlo learning.

Finally, a circular distribution of goals encourages a continuous task variable but permits categorical, Cartesian and search solutions. Behavioral success nominates models for the existing state-perturbation tests; it does not itself nominate a ring. Analyze full h/c and fixed observable maps under the actual constant delay input, with time-matched tangent/radial recovery. Keep pickup direction relative to goal angle fixed within each conditional family and varied across prespecified contexts; do not average away this nuisance to construct a circle.

Use ±30-degree genuine donor states for neural phase displacement, but ±90 degrees for behavioral goal specificity. At radius .75 m, the latter goal centers are 1.061 m apart and their .30 m disks are disjoint; the 30-degree centers are only .388 m apart and their disks overlap. Prefer substitution of incoming h/c immediately before the first FREE recurrent input, processing that input exactly once. Keep the recipient's actual goal and reward unchanged; derive donor-disk entry and progress from saved physical positions.

For repair, replace existing blank delay inputs rather than adding time. Using zero-based recurrent input indices, edit the incoming state at 30, present a correct, ordinary or wrong **goal cue** at inputs 30–44 for the primary 15-update intervention, and restore blank goal inputs at 45–59. The fixed secondary assay supplies its single cue only at input 30, then blanks 31–59. Both first FREE inputs remain at 60. Retain equal-aged unedited and blank/native/ordinary/wrong controls for each duration, identical physical state/tapes, and complete subsequent cue withdrawal. Report each branch's own cue-offset state as well as the common release state; withdrawal-to-release duration differs although total recurrent age is identical. The ±90-degree behavioral donor swap immediately before input 60 is a separate specificity test. Rewriting a displaced goal memory and strengthening autonomous transverse attraction are separate measurements. This keeps the proposed mechanism inside the native navigation LSTM.
