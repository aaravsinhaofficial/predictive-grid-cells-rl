# What the endpoint predictive cue adds

**Interpretation audit, written while the fixed local-return training runs are in progress. No new model outcomes were computed.** This note interprets the unchanged [task implementation](../../scripts/local_goal_return_training.py) and [prospective mechanism test](local_return_mechanism_design.md); it changes neither protocol.

The endpoint PGC pulse supplies a fresh direction-dependent pattern. The ordinary network can also infer direction from earlier observations and actions. Therefore, **a cue can be redundant with an accurate memory and still repair an inaccurate memory**. The frozen behavior test asks whether retained information is useful. The frozen state/cue intervention asks whether this particular predictive pulse can correct that information.

The ordinary network has three possible information routes. First, the 15 visible updates contain actual room images, which can help identify orientation. Second, the previous-action input reports the actual forced turns, so a recurrent network can update an orientation estimate using the learned motor dynamics and task boundaries. The preparatory motor dynamics are noiseless. Third, the network receives an ordinary position snapshot at blackout entry and an updated ordinary snapshot after four forward actions. The pre-probe brake makes this a straight displacement along the probe heading. Remembering the first spatial pattern and comparing it with the second can reveal displacement direction, provided the population code and context resolve spatial ambiguities. These are available computational routes, not claims that a trained network actually implements each one.

From the native equations, the four-step displacement is approximately **4.33 cm**: with decision interval 4/60 s, time constant 0.25 s, initial forward speed zero and target speed 0.35 m/s, it is `sum_k (4/60) × 0.35 × [1 − exp(−k × (4/60)/0.25)]`, for k=1…4. This number is an arithmetic consequence of the frozen physics, not a new rollout result. The held code does not update during the intervening blind turns or during individual probe steps; the endpoint refresh makes the comparison possible.

The predictive cue expresses direction **in the current input**, without requiring that temporal comparison. In this configuration, 169 of the 512 current-code entries evaluate their ordinary rate maps at `endpoint + 0.20 m × actual travel direction`; the other 343 entries retain their ordinary values. This is the repository's fixed spatial-shift code, not a newly supplied angle label. The endpoint observation is read before the post-probe motor brake. Actual travel direction aligns with body heading during the straight probe; subsequent LEFT turns change body heading while the last travel direction remains the probe direction. Those two angles must stay separate in the interpretation. See [the code definition](../../code/codes.py).

**The endpoint replacement is a narrow intervention.** It replaces the predictive CURRENT entries for that single pulse with their ordinary values. It retains the trained weights, native saved-goal code, and predictive inputs received during the visible period. At trial setup, the last-travel vector is initialized to the initial body heading; it then stays fixed during stationary visible turns, supplying an earlier directional reference in PGC inputs. The saved goal is produced by an actual setup pickup and is identical across heading variants within a context. Its pickup direction therefore cannot reveal which heading variant is being evaluated. Neither retained input should be described as ablated.

In the controlled family, all headings finish at the same endpoint with the same saved goal. The ordinary endpoint input and subsequent ordinary LEFT-delay inputs are consequently common across those headings within a network. A ±30° pre-cue h/c swap substitutes the internal state produced by another genuine heading history while retaining the recipient's physical state and cue. With ordinary input, the swapped state follows the donor's recurrent continuation, up to the recorded numerical precision. With the native predictive input, the recipient's actual travel direction is still available to correct the mismatch. Information that was redundant with the intact external history can thus become informative after its internal representation has been changed.

The swap replaces the complete state, including every other history feature correlated with heading. Direction-specific effects, opposite wrong-cue controls, radial/random controls, and the prespecified geometry checks determine whether its effect is well described as directional phase repair. In addition, training includes blind recurrent-state noise while the primary evaluation is clean; the usefulness of a fresh cue need not be identical in those conditions. This observation introduces no change to the fixed evaluations.

| Possible measured outcome | What it would suggest |
|---|---|
| Intact native and ordinary behavior agree; a correct pulse rescues a ±30° swap | The cue is redundant when the memory is consistent, but useful for correcting a conflicting internal history. |
| Both endpoint removal and swap rescue have little effect | Low use of this pulse in these conditions. Earlier cues, another memory computation, or weak actor access remain distinct possibilities. |
| Persistent phase correction after withdrawal, with improved navigation | Predictive input helps anchor a recurrent directional computation that the actor uses. |
| Phase correction with little navigation change | A corrected representation has little behavioral influence in the measured trials. |
| Navigation rescue without the fixed ring criteria passing | Useful cue-mediated recurrent correction through a different state organization. |

The hard-task gate—at least 167/256 intact successes and a loss of at least 39 after post-cue erasure—screens for useful retained information. The separate paired-history certificate bounds success using the common remaining information: its 50% ceiling applies only when every pair passes its physical and input checks. These tests concern **memory need**, not exclusive PGC need. The native/ordinary/wrong-cue comparisons concern the predictive pulse. The full-state and fixed-observable tests concern the computation's geometry and attraction. A one-step cue changes state; after withdrawal, it leaves the recurrent weights and subsequent transition rule unchanged. Correcting angular phase and strengthening autonomous transverse attraction are therefore separate measurements.

Biological work motivates this distinction. Seelig and Jayaraman observed a fly heading representation using visual landmarks when available and self-motion in darkness, illustrating complementary sensory and internally updated information. [Nature, 2015](https://www.nature.com/articles/nature14446). Fisher and colleagues measured visual inputs to the heading circuit and experience-dependent changes in its coordinate frame, linking sensory input to a recurrent heading estimate. [Nature, 2019](https://www.nature.com/articles/s41586-019-1772-4). Kim and colleagues optogenetically replaced the heading representation and observed its persistent naturalistic dynamics, motivating direct state interventions when testing an attractor. [Science, 2017](https://pubmed.ncbi.nlm.nih.gov/28473639/). These studies support the logic of separating cue anchoring from internal dynamics; the frozen LSTM experiments supply the evidence for this particular agent.
