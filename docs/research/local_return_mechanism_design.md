## Exact cue and action timing

Let **g** be the task's endpoint-cue input index, after the four forward actions.

| Quantity | What has happened | What happens next |
|---|---|---|
| Pre-cue `(h,c)` | Last probe input processed and last forward action completed | Apply the state edit, then process cue input g |
| State 0 | Cue input processed; previous action is FORWARD | First forced LEFT action |
| State k, 1≤k<60 | k LEFT actions completed; common ordinary input processed | LEFT action k+1 |
| State 60 | 60 LEFT actions completed; first FREE input processed | First learned action uses `pi(h)` directly |

In the frozen collector, code is computed from the actual endpoint observation **before** the post-probe motor brake. Use that actual travel direction and observed velocity for the native/rotated cue. Do not substitute the later turning body's heading or recompute a velocity-dependent code after braking. The four-forward history aligns travel and body direction here; verify rather than assume it.

After the single cue, every phase/cue branch within a model receives the same black-image embedding, ordinary endpoint code, fixed saved goal, previous action LEFT and previous reward 0. The input at g has previous action FORWARD and is a separate input. The constant-input neural map begins after that cue. During LEFT motion, actual body heading changes with native angular inertia while stored travel direction remains the probe direction. Use the simulated physical turn, not `2.2 × elapsed seconds`, to distinguish initial-direction memory from integrated heading.

## Fair comparisons and interpretation

The primary acute cue comparison is exact within each frozen network. Both populations share the same physical contexts. Their saved native goal vectors and learned black-image CNN embeddings may still differ, so their native-delay inputs are not automatically byte-identical across populations. A stability difference here describes the trained systems in their respective task conditions.

If a claim specifically concerns a cross-population recurrent difference under the same numerical input, add a separately labeled crossed-input sensitivity: each of the two native 1×1287 ordinary-delay input vectors is supplied to both networks, starting from each network's own elicited family. Keep both backgrounds and all outcomes; do not pick the favorable source. This holds input fixed for the contrast while preserving the caveat that the state families and trained coordinates differ. It is a conditional control, not a required expansion when no circular candidate exists.

A single PGC pulse changes the recurrent state; once it is withdrawn, it does not change the weights or common transition law. It could repair phase, bring the state back toward an attracting set, or place it in a more robust region of that set. These are measurable alternatives. **Faster transverse recovery**, **corrected phase**, and **better navigation** are reported separately, then connected by the factorial intervention. Even a strong result in this new task concerns the adapted networks with new readouts; the original-agent performance mechanism remains a separate question.

For qualifying candidates only, inspect full 512-state Jacobians at the four prespecified quarter-circle samples and anchors 15/30, plus finite-time products through 60. Report tangent, radial and worst transverse gains/eigenvectors and nonnormal effects. At moving states, an instantaneous Jacobian maps between different points; finite-time tangent transport and transverse recovery carry the stability interpretation, rather than requiring an instantaneous eigenvalue of exactly one. Call a product Floquet only after verifying a return period. A candidate-update/output-gate cue-path intervention is a later focused localization test motivated by the repository's previous result, not an extra gate or automatic large search.

## Primary literature informing the test

[Ságodi et al., *Back to the Continuous Attractor*, version 2](https://arxiv.org/html/2408.00109v2) analyze noise-trained recurrent networks, including LSTMs, through noise-free trajectories, slow manifolds, flow and local spectra. Their LSTMs can have discrete fixed points arranged on a slow ring. This motivates separating task-duration attraction from phase flow, rather than demanding infinitely many exact fixed points; their supervised task does not supply evidence for this RL agent.

[Low, Giocomo & Williams, eLife 2023](https://elifesciences.org/articles/86943) connect context-specific navigation rings to full-state fixed points and Jacobian eigenvectors in trained RNNs. Their input-conditioned analysis motivates holding the actual numerical input explicit and examining tangent versus other modes. Their training objective and recurrent architecture differ from this task.

[Song, Yang & Wang, eLife 2017](https://elifesciences.org/articles/21492) demonstrate reward-trained recurrent working memory, including variable 2.7–3.3 s delays. This supports using behavior to establish a learned memory demand first. Circular geometry and its causal use require the additional tests above.
