# Provisional rationale for native turn-memory distillation

**Design recommendation only, 6 November 2026.** The teacher preflight is undergoing technical review and has not run. This note launches no evaluation, optimization or cloud work and changes no frozen study. The concrete event and preflight are described in the [minimal plan](native_turn_distillation_minimal_plan.md).

**The task creates a useful need for history. Continuous angular memory is a possible solution.** After different turn histories, two agents can have the same complete current input and motor state but different body headings. A single memoryless action distribution then cannot reproduce distinct teacher choices for those histories. Because this agent can move forward, backward and sideways, the relevant computation is choosing a useful body-relative movement. It may retain egocentric goal bearing, an earlier movement reference, a coarse action category or a turn counter. At fixed goal and position, goal bearing and heading are related by a rotation and sign; that context alone cannot identify the remembered variable. The preflight retains both action-distribution differences and actual teacher navigation usefulness.

Varied physical phases and signed turn histories supply opportunities to learn a continuous calculation. The six action outputs and three measured choices can still be solved coarsely. Fresh ordinary position codes after the measured window also permit direction reacquisition. Keep the first ambiguous choice, subsequent blind choices and later feedback-supported navigation separate. The existing saved goal stays available. These are useful task constraints, not an imposed angular representation.

**Give the ambiguous choices a substantial learning signal.** Recommend the declared objective

`loss = 0.5 × mean(choice teacher KL) + 0.5 × mean(other controlled-decision teacher KL)`.

Both means use forward KL from the actual full-vision teacher probabilities to the student probabilities. Forced actions remain excluded from the direct imitation loss; gradients from later choices still pass through their recurrent updates. The existing single mean runs over policy-controlled decisions, so dilution is not literally three choices out of every 90 updates. Nevertheless, the three choices can receive only a small fraction of the total loss, especially when events are uncommon. Separate means make their importance explicit. If a batch contains no ambiguous choices, use the ordinary control mean alone and record zero choice exposure; do not report that batch as memory training. Specify the symmetric handling of an empty control category before implementation. Save both counts and both losses. This weighting has negligible computational cost and may trade some visible-policy fidelity for improved blind choices, which the full-vision evaluation measures.

**Weak state noise is a direct robustness pressure.** Increasing a noiseless delay mainly rewards persistence; a neutral, nonattracting trace can persist. Small unpredictable recurrent perturbations make accurate action imitation depend on resisting state errors. Use one prospectively fixed, scale-aware amplitude, with explicit hidden/cell injection timing and separate fixed scale conventions. Record the realized perturbations, including any bounded-state transformation, and replay the same samples during BPTT. Keep the teacher clean, preserve the actual inputs and physics, use private randomness, and choose no perturbation direction from a fitted ring.

Prespecified random blind perturbation times should include opportunities before the genuine probe cue and after its withdrawal. Pre-cue corruption makes useful cue-based re-estimation learnable; later corruption supplies pressure for recovery without a new directional observation. Generic noise also perturbs the remembered direction itself, so it can cause diffusion or favor coarse stable categories. Clean geometry tests must therefore measure retention and selective recovery separately. The earlier [reward-only noise continuations](../../mechanisms/learned-ring-in-navigation.md#longer-adaptation-and-activity-noise) already showed that adding noise to this repository's original blackout task was insufficient for the tested ring criteria. The proposed combination adds an input-ambiguous native event, a dense teacher signal and explicit choice weighting.

**Use weak noise for training, not complete erasure.** Erasure deletes the entry-position/history route used by ordinary grids, while a genuine predictive cue still contains information about the probe's travel direction. That is a useful information-recovery diagnostic with a declared asymmetry. It is not a matched small disturbance. Keep erasure in evaluation. Weak perturbations retain both information routes, and native-versus-ordinary cue interventions test their usefulness within a trained model. The PGC cue must use measured travel direction; body heading continues changing during the subsequent turn.

**The minimal interpretable comparison is four fixed runs:** Grid and PGC, each with the same weighted objective under zero and weak state noise. Within each population, start both arms from the identical original checkpoint and use the same optimizer, event schedule, cue mixture and fixed endpoint. Couple the underlying random tapes; later learner trajectories can still diverge. At 180 updates per run this would total 4,147,200 physics frames, doubling the two-model training allocation. A single noisy pair would test the combined recipe; the matched clean arms identify the effect of adding noise. This remains a recommendation pending the complete descriptive preflight and a separately frozen acquisition decision.

The literature motivates this robustness pressure. [Ságodi and colleagues](https://arxiv.org/html/2408.00109v2) trained vanilla, LSTM and GRU networks with state noise on continuous angular-memory objectives and identified attracting slow manifolds (§4.1, §6, S7.7). [Cueva and colleagues](https://arxiv.org/html/1912.10189v2) trained noisy recurrent networks to integrate angular velocity using sine/cosine heading targets (§2). **Our loss contains native action probabilities; it contains no heading label, sine/cosine target, angular decoder loss or prescribed ring geometry.** Useful continuous memory, transverse stability and predictive-cue repair remain empirical properties to measure at the fixed endpoints.
