# How to interpret the exploratory original-goal-memory test

Written before the separate memory-bank outcomes. The original training proposal stopped at its paired qualification gate: Grid 181/256 and PGC 236/256, against 192 required for each. That result remains unchanged. The separately registered evaluation uses both fixed original seed 1 networks, all 11 branches and the same previously sealed 256-case memory bank, with no learning. It asks whether useful goal memory already exists. One trained pair supports descriptive comparisons, not population-level significance.

**First establish what the recurrent state does for behavior.** Retain the existing descriptive screen: at least 167 brief-native successes and at least 39 fewer successes after post-cue erasure, with all 256 cases valid. Examine genuine ±90° donor-state interventions as well: does the recipient move toward the donor goal during the first 15 FREE updates, rather than simply lose performance? Self-swap, no-cue and wrong-cue branches help interpret this. Early progress holds the terminal position for short trials; full-path donor entry is censored by the actual recipient first hit. No result automatically nominates a model for neural analysis: artifact audit and scientific review come first.

**A. Useful, goal-specific memory: one release-and-perturb experiment.** If the screen and donor steering support memory use, the proposed follow-up uses fixed contexts 0/1 and both original networks. Elicit dense goal families through the actual 15-update stationary cue, then withdraw the entire goal input. During blank slots 15–59, RGB, current code, previous action and reward are identical across goal phases. Thus all states evolve under the same recurrent transition; the variable being remembered is goal direction, not body heading.

Reuse the existing full-state and fixed future-observable tests and thresholds. A candidate should preserve angular coverage and signal amplitude, approach an approximately invariant closed curve, and repair targeted radial and other transverse disturbances faster than angular disturbances. Slow angular drift or preferred points can coexist with an attracting ring; an exact continuum of fixed points is unnecessary. This is the fast–slow distinction demonstrated in trained LSTMs by [Ságodi and colleagues](https://arxiv.org/html/2408.00109v2#S7.SS7). Their networks used supervised angular tasks and state-noise training, so their result supplies an analysis method, not an expected outcome here.

Only a surviving candidate motivates the proposed cue-repair test: replace incoming state by a genuine ±30° goal-family state at slot 30; provide a 15-update native, ordinary, wrong or blank goal cue at 30–44; withdraw it again. Keep the separately specified one-update pulse diagnostic, matched unedited controls, common age 60 and recipient physics. Ask whether correction persists and improves native navigation. Autonomous transverse attraction and predictive cue correction are separate measurements. If a fixed observable map supplies the candidate, measure rescue in that same map as well as in behavior.

**B. Continuous cue works, brief cue fails: stop expensive ring work for this task.** This pattern suggests useful steering that depends on the continuing goal signal. If early donor steering survives despite poor hit rates, report retained goal information with a behavioral limitation. Successful continuous-reset trials allow 45 further cue-present updates to rebuild state; they do not identify a feedforward controller. Withdrawal also changes an input that the original navigation task supplied continuously, so this result concerns the tested operating condition.

Two distinctions remain essential. Brief-ordinary replaces only the 169 predictive **goal** channels during initial encoding; all goal channels then disappear, and current predictive input remains intact. That comparison concerns encoding, not a later repair pulse. Also, the earlier goal-family assay already found about 70% state separation after withdrawal, with nearly identical native/ordinary PGC persistence and no convincing preferential transverse recovery. A new loop or angle decoder would repeat that evidence. Useful memory can also arise from other dynamics: [Park, Ságodi and Sokół](https://arxiv.org/html/2308.12585v1#S2.SS11) construct angular memory using relative oscillator phase. The new discovery would have to be behaviorally used memory with measured attraction and predictive repair, or a clearly identified alternative.
