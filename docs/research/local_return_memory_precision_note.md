# Later memory precision: coarse states versus a slow ring

**Design note only. The acquisition control remains exactly revision 2.** No task, bank, gate, model or experiment changes follow from this note.

A straight path from distance D to a circular goal of radius R can intersect the goal when its directional error is at most asin(R/D), ignoring finite travel length and inertia. With R=.30 m and D=.58–.62 m, this geometric tolerance is approximately **±29–31°**. The actual two-second motor task imposes additional constraints. Nevertheless, success may reward a coarse remembered movement category instead of high-precision angular memory. Eight equally spaced direction categories would have at most 22.5° quantization error in this idealized geometry; that is an illustration, not a model of the agent's six actions or an observed solution.

If a later agent passes the unchanged useful-memory gate, the existing dense native-history assays should distinguish:

- **Coarse persistent categories:** nearby initial directions converge into a few state groups during the task interval; intermediate-angle distinctions disappear, and small phase shifts often leave behavior unchanged until a category boundary is crossed. Such an agent may use valuable memory without satisfying the frozen circular-manifold criteria.
- **A slow attracting ring:** densely sampled intermediate directions remain ordered along a noncollapsed closed family during the relevant interval, with faster transverse than tangential recovery and consistent phase-dependent behavior. Eventual convergence to several preferred states does not by itself exclude this finite-time mechanism.
- **A continuous but nonattracting trace:** direction remains represented, but radial or other transverse disturbances are not preferentially corrected. This is a different mechanism even if its decoder and navigation are accurate.

Use the full-state and already specified future-observation maps, unchanged gates, actual physical angle/turn accounting, and targeted radial as well as random perturbations. Keep the donor-state and correct/ordinary/wrong-cue navigation contrasts. Neither a ring-shaped plot nor a few fixed points alone resolves the classification. Ságodi and colleagues explicitly trained a continuous sine/cosine angular target and found slow rings in gated networks with varying numbers of stable points and saddles; their finite-time distinction is directly relevant here. [Primary paper, task S7.1 and gated-network analysis S7.7](https://arxiv.org/html/2408.00109v2).

A **separate prospective precision comparison** becomes scientifically useful only after reliable memory-based navigation exists and the question is whether coarse reward tolerance selects coarse memory. Reducing the pickup radius is a simple candidate manipulation of the same arena/reward task, with unchanged native architecture and no angle supervision. It also increases required travel and reduces reward availability, so any such design must first establish comparable physical opportunity and successful learning at its fixed endpoints. It should retain the original-radius comparator and failed learners, use a new sealed bank, and apply the same ring criteria. No radius or duration search is warranted from the current failures. A positive result would concern task-dependent emergence under the new precision demand, not retrospectively establish a ring in the original agents.
